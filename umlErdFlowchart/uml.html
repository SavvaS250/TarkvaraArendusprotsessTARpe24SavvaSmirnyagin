UML Diagrammid

Mis on UML?

Unified Modeling Language (UML) on standardne modelleerimiskeel, mida kasutatakse tarkvara ja süsteemide kirjeldamiseks diagrammide abil.


UML diagrammide tüübid

  • Use Case Diagram
  • Class Diagram
  • Sequence Diagram
  • State Diagram
  • Component Diagram
  • ERD Diagram
  • Flowchart / Activity Diagram


Use Case Diagram

Use Case diagramm kirjeldab süsteemi funktsionaalsust kasutaja vaatepunktist.

Elemendid

  • Actor - süsteemi kasutaja
  • Use Case - süsteemi tegevus
  • Seosed - ühendused kasutaja ja tegevuste vahel

Näidis

Kasutaja -> Logib sisse süsteemi


Class Diagram

Class diagramm näitab klasse, omadusi, meetodeid ja seoseid.

Elemendid

  • Klass
  • Atribuudid
  • Meetodid
  • Seosed

Näidis

User class sisaldab name ja email atribuute.


Sequence Diagram

Sequence diagramm näitab objektide omavahelist suhtlust ajajärjestuses.

Elemendid

  • Object
  • Lifeline
  • Message

Näidis

Kasutaja saadab login päringu serverile.


State Diagram

State diagramm kirjeldab objekti erinevaid olekuid.

Elemendid

  • State
  • Transition
  • Start State
  • End State

Näidis

Ootel -> Töötleb -> Lõpetatud


Component Diagram

Component diagramm näitab süsteemi komponente ja nende sõltuvusi.

Elemendid

  • Component
  • Dependency
  • Interface

Näidis

Frontend -> Backend -> Database
